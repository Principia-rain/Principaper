# 如何在本站写一篇论文（示例）

> 这篇页面本身就是一篇普通的 Markdown 文件，存放在仓库的 `papers/` 目录里。
> 你可以打开 `papers/示例论文.md` 对照着看。

## 1. 文件开头：元信息（front matter）

每篇论文用一个 `---` 包起来的块声明元信息（可选，但强烈建议写）：

```yaml
---
title: 论文标题
author: 你的名字
date: 2026-10-21
tags: [标签1, 标签2]
abstract: 一两句摘要，会显示在首页卡片上。
code: https://github.com/某人/某仓库
---
```

| 字段 | 作用 | 缺省行为 |
|---|---|---|
| `title` | 标题 | 用文件名 |
| `author` | 作者 | 不显示 |
| `date` | 日期（首页按它排序） | 排到最后 |
| `tags` | 标签（逗号分隔） | 无 |
| `abstract` | 摘要（首页卡片显示） | 无 |
| `code` | 代码仓库链接（可多个，逗号分隔） | 无 |

## 2. 公式：直接写 LaTeX

行内公式写在两个 `$` 之间：质能关系 $E = mc^2$，约化普朗克常数 $\hbar = h / 2\pi$。

独立公式用两个 `$$`：

$$
i\hbar\,\frac{\partial}{\partial t}\Psi(\mathbf{r},t)
= \left[ -\frac{\hbar^2}{2m}\nabla^2 + V(\mathbf{r}) \right]\Psi(\mathbf{r},t)
$$

多行推导用 `aligned` 环境（麦克斯韦方程组）：

$$
\begin{aligned}
\nabla \cdot \mathbf{E} &= \frac{\rho}{\varepsilon_0}, \\
\nabla \cdot \mathbf{B} &= 0, \\
\nabla \times \mathbf{E} &= -\frac{\partial \mathbf{B}}{\partial t}, \\
\nabla \times \mathbf{B} &= \mu_0 \mathbf{J} + \mu_0\varepsilon_0 \frac{\partial \mathbf{E}}{\partial t}.
\end{aligned}
$$

## 3. 代码

代码块自动高亮：

```python
import numpy as np

def oscillator(t, omega=1.0):
    """简谐振子的一小段演示代码"""
    return np.cos(omega * t), -omega * np.sin(omega * t)
```

行内代码像这样：`pip install numpy`。

## 4. 表格、引用与列表

> 引用块：适合放备注、出处或题外话。

1. 有序列表；
2. 支持 **加粗**、*斜体*、[链接](https://pages.github.com/)。

## 5. 图片

把图片和论文一起上传到 `papers/` 目录（可以建子文件夹，如 `papers/我的论文-图/`），然后在 Markdown 里用相对路径引用：

```markdown
![图 1：相图](我的论文-图/fig1.png)
```

（本示例不含图片文件，避免仓库变大。）

## 6. PDF 论文

PDF 直接上传即可，访客可在浏览器里直接翻阅。若想让首页卡片显示标题/摘要等信息，再上传一个**同名 JSON**（如 `my-paper.pdf` 配 `my-paper.pdf.json`）：

```json
{
  "title": "论文标题",
  "author": "作者",
  "date": "2026-10-21",
  "abstract": "摘要……",
  "tags": ["凝聚态"],
  "code": "https://github.com/某人/某仓库"
}
```

## 7. 引用别人的代码仓库

front matter 里的 `code` 字段会在首页卡片和阅读页生成「💻 代码仓库」按钮——本示例挂了两条：本站的公式渲染用的是 [KaTeX](https://github.com/KaTeX/KaTeX)，Markdown 渲染用的是 [marked](https://github.com/markedjs/marked)，向这两个开源项目致谢。
